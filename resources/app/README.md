# IP 桌面宠物 · 工作流

把**任意你喜欢的 IP / 表情包**变成一只会在桌面跑、会动、能摸、能喂的虚拟宠物。
本仓库是一个**可复用模板**：换图片、改名字，就是你的专属桌宠。

---

## ⚠️ 关于「下载图片」的重要说明（必读）

本助手运行在**沙箱环境**：Bash 没有外网出口，且贴图站（GIFDB / Tenor / emoji.gg）都用 Cloudflare 拦截爬虫，
所以**助手没法在这个环境里把 GIF 二进制抓到本地**。图片需要你在**自己的电脑**上准备（你的机器有正常网络）。

准备图片有两种方式，任选其一：

**方式 A · 手动（最稳，推荐）**
1. 浏览器打开 `https://gifdb.com/mochi-cat`（或其它你喜欢的 IP 表情包站点）
2. 逐张右键 →「图片另存为」，存进本仓库的 `assets/` 文件夹
3. 按状态重命名，例如：`mochi-idle.gif`、`mochi-happy.gif`、`mochi-sad.gif` …

**方式 B · 自动（Playwright，可选）**
贴图站拦普通 curl，但拦不住真实浏览器。用 Playwright 启动 Chromium 把全套抓下来：
```bash
npm i -D playwright
npx playwright install chromium
node download-mochi.js        # 抓到 assets/，再挑 6 张对应状态
```

> 你也可以在 `pet.html` 的 `PET.states[].src` 里**直接填网络直链**（右键图片 →「复制图片地址」），
> 不用下载，浏览器/Electron 会实时加载。把直链贴给助手，助手能直接帮你嵌好。

## 🐾 三步变成你的桌宠

**1. 收集表情包** —— 准备 4~6 张不同状态的 GIF（待机/开心/委屈/摸鱼/睡觉/震惊…），放进 `assets/`。

**2. 配置** —— 打开 `pet.html`，改最上面的 `const PET = {...}`：
- `name`：宠物名字
- `size`：显示大小
- `states`：每个状态的 `key` / 按钮 `label` / 图片 `src`（本地路径或直链）
- `meters` / `lines`：状态条与台词（可删）

**3. 打开** —— 直接双击 `pet.html` 用浏览器打开就能玩：
- 拖动宠物满屏跑
- 点一下「摸头」→ 蹦跳 + 冒爱心
- 底部按钮切换状态；状态条会随时间下降，钱包见底自动变「生无可恋」
- 点「🖥 桌面宠物模式」→ 透明背景，只剩猫（适合当真桌宠）

## 🖥 打包成悬浮桌面的 exe（可选）

想让它真正脱离浏览器、透明悬浮在所有窗口之上：

```bash
npm install
npm start          # 立即以透明置顶窗口运行（可拖、可右键摸头/喂食）
npm run pack       # 打包成可安装的 .exe（输出在 dist/）
```
- `main.js` 已配好：透明背景 + 无边框 + 始终置顶
- 右键托盘/宠物有「摸摸头 / 喂一口 / 退出」菜单

---

## 🔁 换成「任意 IP」

整套流程对 IP 零依赖，只要你有这个 IP 的表情包 GIF：
1. 把 `assets/` 里的图换成你的 IP（命名对应状态）
2. 改 `PET.name` 和 `states` 的 `label`
3. 打开 / 打包 —— 完事

常见可做的 IP：Mochi Cat、Peach & Goma、线条小狗、小刘鸭、任何你收藏的猫猫狗狗表情包。
