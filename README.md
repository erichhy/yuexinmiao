# 月薪喵 🐱💸

一只**会自己花钱、会破产、会死给你看**的打工猫桌面宠物。

基于 Electron 的透明悬浮桌宠。它常驻你的屏幕右下角：会散步、会追逗猫棒、被摸头会蹦跳冒爱心 ——
也会因为每天的生活开支把钱包花穿，然后趴在桌上哭给你看。

## 玩法

**三条数值**

| 数值 | 说明 |
| --- | --- |
| 心情 | 随时间缓慢下降（每 8 秒 −0.1）；散步时会回升 |
| 好感 | 互动累积，越高越亲 |
| 钱包 | 发薪日进账；**每天自动扣生活开支 ¥20**；玩耍一次 ¥50 |

**互动**：摸头 · 挠痒 · 喂食 · 玩耍 · 嗅闻 · 把我抛起来

**模式**
- **散步**：沿屏幕边缘顺时针绕圈，全程不出屏
- **逗猫棒**：全屏出现红点，猫会追着光点跑（Esc 退出）

**破产机制**：钱包被扣到负数时，猫会「因穷困离世」—— 趴桌痛哭 + 死亡横幅，
成就、心情、好感、钱包全部清零，点「重新投胎」重开一局。
（死亡状态会保留到下次打开，直到你让它投胎。）

**成就**：达成条件解锁小图标，贴在猫身边。

**快捷键 / 入口**：右键猫或托盘图标唤出菜单，`Alt + P` 打开操作面板。

## 从源码运行

需要 [Node.js](https://nodejs.org/) 与 Electron：

```bash
git clone https://github.com/erichhy/yuexinmiao.git
cd yuexinmiao
npm install electron
npx electron resources/app
```

## 目录结构

```
resources/app/
├── main.js              主进程：窗口管理、散步、逗猫棒、托盘与右键菜单
├── pet.html             猫本体：状态机、动画、数值与存档
├── panel.html           操作面板（Alt + P 打开）
├── states.js            状态定义
├── catalog.js           素材目录
├── preload-*.js         渲染进程桥接
├── teaser.html / cursor.html
└── assets/              猫的素材（121 张表情包 GIF / PNG）
```

Electron 运行时二进制不入库，请从 Releases 下载完整绿色版。
